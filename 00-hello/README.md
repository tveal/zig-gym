# Hello World

https://ziglang.org/documentation/0.16.0/#Hello-World

## Prerequisites

- mise (https://mise.jdx.dev/) - used for managing zig runtime

## zig commands

Serve the Standard Library Doc locally with
```sh
zig std
```

List the available build commands (steps)
```sh
zig build -l
```

Build the app to `zig-out/bin/`
```sh
zig build
```

Run the app without building the binary
```sh
zig build run
```
